# Source Artwork

This directory keeps EMORI's intentional high-resolution and variant source
artwork for future avatars, skill icons, stickers, and release art.

- `icon-large*.png` and `composer-icon.svg` are source icon artwork.
- `emori-sticker*.png` are source sticker variants.

Runtime-ready derivatives belong in `avatars/`, while skill-specific derivatives
belong in `skills/*/assets/`. Exact copies may remain here as source material and
should not be pruned only because the current repository does not reference
them directly.
